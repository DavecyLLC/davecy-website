# Davecy LLC website

React + Vite website for engineering services, desktop applications, and product inquiries. Hosting remains on Vercel.

## Development

```sh
npm ci
npm run dev
npm run build
```

## Product and service inquiries

The contact form submits to the existing Formspree endpoint in `src/App.jsx`. Product inquiry links preselect the product in the form; visitors can change their selection. No messages are sent until the visitor submits the form.

Verify Formspree delivery in the account before relying on it for leads. Product descriptions invite inquiries rather than implying confirmed release dates, store listings, pricing, or demo availability. Replace inquiry links with verified product destinations when available.
