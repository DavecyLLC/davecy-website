# DAVECY LLC Phase 7 - Improved Contact

## Run

npm install
npm run dev

## Improved Contact Form Includes

- Name
- Email
- Company / Organization
- Project type
- Budget range
- Timeline
- Project message
- Direct contact card
- Demo success message

The form is front-end only. Connect it to Formspree, EmailJS, Firebase, Resend, or your backend to receive real messages.
